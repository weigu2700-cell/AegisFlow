# AegisFlow

**面向企业业务自动化场景的 AI Agent 与 Skills 工作流平台。**

AegisFlow 让用户通过自然语言发起任务，由 Agent 完成任务规划、技能发现、工具调用和结果反馈，并提供人工审批、状态恢复、执行追踪与评测能力。

> **项目状态：开发中。** 前端工程已初始化，后端与 Agent 能力仍在规划阶段。

## 项目简介

企业业务流程往往涉及多个系统、复杂规则和需要人工确认的操作。AegisFlow 通过状态化 Agent 工作流，把自然语言任务转化为可追踪、可控制的执行步骤，并通过可复用的 Skills 接入业务能力。

## 核心功能

- **任务规划与执行**：将自然语言需求拆解为任务步骤，执行并返回结果。
- **Skills 管理**：统一描述技能、输入输出和执行约束，支持注册、发现、参数校验与调用。
- **工具集成**：通过 MCP 协议接入外部工具和业务系统。
- **人工审批**：对高风险操作进行权限检查，并在需要时等待人工确认。
- **状态恢复**：持久化工作流状态，结合检查点和幂等机制降低中断及重复执行的影响。
- **知识检索**：通过文档处理、检索和上下文组装，为 Agent 提供知识支持并返回引用。
- **追踪与评测**：记录模型响应、工具调用、工作流节点和错误，评估任务执行与异常恢复情况。

## 技术栈

### 前端

| 类别 | 技术 | 说明 |
| --- | --- | --- |
| 框架 | React 19 | 函数组件 + Hooks，启用 React Compiler |
| 语言 | TypeScript 7 | 严格类型检查，`tsc -b` 参与构建 |
| 构建工具 | Vite 8 | 开发服务器、HMR 与生产构建 |
| 包管理 | pnpm | 依赖安装与锁文件管理 |
| 代码检查 | Oxlint | 快速静态检查 |

### 后端

| 类别 | 技术 | 说明 |
| --- | --- | --- |
| 语言 | Python | 后端服务与 Agent 逻辑 |
| Web 框架 | FastAPI | HTTP API 与依赖注入 |
| 数据校验 | Pydantic | 请求/响应模型与配置校验 |
| 工作流编排 | LangGraph | 状态化 Agent 工作流 |
| 工具协议 | MCP | 外部工具与业务系统接入 |
| 数据与缓存 | PostgreSQL、Redis | 持久化与缓存 |
| 部署 | Docker | 容器化运行 |

## 工作流程

```mermaid
flowchart LR
    A[提交自然语言任务] --> B[Agent 任务规划]
    B --> C[发现并选择 Skills]
    C --> D[校验参数与执行约束]
    D --> E{需要人工审批?}
    E -- 是 --> F[等待人工审批]
    F -- 通过 --> G[调用工具并执行]
    F -- 拒绝 --> J[结束任务并反馈]
    E -- 否 --> G
    G --> H[校验执行结果]
    H --> I[返回结果与引用]
```

知识检索可在需要时为任务提供上下文。执行过程中会记录状态和调用信息，并通过检查点支持恢复。

## 快速开始

### 环境要求

- Node.js 20.19+ 或 22.12+
- pnpm 10+
- Python 3.12+（后端，规划中）

### 前端

```bash
cd frontend/frontend
pnpm install
pnpm dev        # 启动开发服务器，默认 http://localhost:5173
```

常用命令：

| 命令 | 说明 |
| --- | --- |
| `pnpm dev` | 启动开发服务器（HMR） |
| `pnpm build` | 类型检查并构建生产产物到 `dist/` |
| `pnpm preview` | 本地预览生产构建 |
| `pnpm lint` | 使用 Oxlint 检查代码 |
